# 虚拟环境总结大全

### 为什么要用虚拟环境

当你的电脑中有多个要运行的项目时，会面临这样一个问题：不同项目依赖的包的版本不同，有的项目需要这个包的1.0版本，有的项目需要这个包的2.0版本。如果此时没有虚拟环境，那就很麻烦注定有一个项目会遇到问题。此时虚拟环境就登场了，给项目1一个自己的环境，里面装它的所有依赖；给项目2一个自己的环境，里面装它的所有依赖。这样你电脑里的环境就很整齐好打理了，只需要运行哪个项目就启动哪个虚拟环境即可。

### 虚拟环境怎么实现的

1. 电脑在你的项目里新建了一个类似 `.venv` 的隐藏文件夹
2. 把系统里的 `python.exe`复制了一份，或者创建了一个快捷方式（符号链接）放到 `.venv/bin` 或 `.venv/Scripts` 目录下。
3. **激活时劫持环境变量：** 当你“激活”虚拟环境，系统会**临时修改操作系统的 `PATH` 环境变量**。把这个 `.venv` 文件夹的优先级提到最高。这样当y运行时，电脑会优先使用你虚拟环境里的工具，下载的第三方包也会老老实实地存放在 `.venv/lib/site-packages` 里面，而不会污染你电脑的全局环境。
   **虚拟环境的本质就是建立了一个文件夹，包含各种需要的包**

### 常见的包管理工具

1. **`pip` (Python 官方包管理器)：** 它是 Python 自带的。只要你电脑上装了 Python，默认就有 `pip`。它专门去官方的“大仓库”（PyPI）里拉取 Python 代码包。它本身并不能创建虚拟环境，只是用来下载包的，但可用最传统的方式去创建——`.venv + pip`。首先建一个叫 `.venv` 的文件夹充当虚拟环境（Python 自带的模块）。然后再呼叫 **`pip`** 这个快递员，把代码包专门搬进这个虚拟环境里。
   常见的pip操作：

- **`pip install <包名>`**：它不仅会下载你需要的包，还会聪明地把你需要的底层关联的依赖项一并拿回来。
- **`pip uninstall <包名>`**：卸载。
- **`pip list`**：列出所有已安装的包及版本。
- **`pip show <包名>`**：查看某个特定包裹的详细信息。
- **`pip freeze > requirements.txt`**： 它可以把你当前环境里所有的包名和版本号“打印成一张发货清单”。以前没有 `uv` 的时候，大家都是把这个 `.txt` 文件传给同事，同事再用 `pip install -r requirements.txt` 照着清单下载依赖包。

2. **`conda` (跨语言的生态管理器)：** `Conda` 更加庞大。它不仅能安装 Python 包，还能安装 C++ 库、GPU 驱动等底层依赖。
   常见的`conda`操作:

- **`conda create -n myenv python=3.10`**
  - _作用：_ 创建一个名字叫 `myenv` 的全新虚拟环境，并指定 Python 版本为 3.10。
- **`conda activate myenv`**
  - _作用：_ 激活（进入）这个虚拟环境，Conda 必须先手动激活。
- **`conda deactivate`**
  - _作用：_ 退出当前虚拟环境，回到系统全局环境。
- **`conda env list`**
  - _作用：_ 查看你电脑上目前一共建了多少个 Conda 虚拟环境。
- **`conda env remove -n myenv`**
  - _作用：_ 删除名为 `myenv` 的环境。
- **`conda install numpy`**
  - _作用：_ 在当前环境中下载并安装 `numpy` 包。
- **`conda list`**
  - _作用：_ 查看当前虚拟环境里已经安装了哪些包，以及它们的版本号。
- **`conda update 包名`**
  - _作用：_ 把某个包升级到最新版本。

3. **`uv` ：** 极速版、全能版的 pip + venv。用 Rust 写的，速度快到飞起。
   常见的`uv`操作:

- **`uv init`**：初始化一个新项目。
- **`uv add <包名>`**：安装第三方包，并自动写进 `pyproject.toml`。
- **`uv remove <包名>`**：卸载包，并自动从配置文件中移除。
- **`uv run <文件名.py>`**：它会自动使用虚拟环境里的 Python 来运行你的代码，你再也不用手动输入去激活环境了。
- **`uv sync`**：当你从 GitHub 上克隆了别人的项目（或者换了一台电脑），只要有 `pyproject.toml` 和 `uv.lock`，敲下这个命令，`uv` 就会一秒钟帮你把一模一样的虚拟环境复刻出来。
